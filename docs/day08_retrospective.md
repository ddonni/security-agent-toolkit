# 1과목 회고 (곽도현)

## 내가 만든 것
- 주어진 로그 파일에서 보안 경보를 추출하고, LLM을 활용하여 각 경보의 위험도를 평가하고 요약하는 파이프라인을 구현했습니다. 또한, 요약된 정보를 기반으로 보고서를 생성하고, 알림 서버를 통해 팀장에게 보고할 수 있는 기능을 추가했습니다.

## 가장 어려웠던 것
- 서버가 같은 포트에서 여러 번 실행될 때 발생하는 충돌 문제를 해결하는 것이 가장 어려웠습니다. Flask 서버가 이미 실행 중일 때 다시 실행하려고 하면 포트 충돌로 인해 오류가 발생했기 때문에, 이를 방지하기 위해 서버 실행 전에 포트 사용 여부를 확인하고, 필요 시 서버를 종료하거나 다른 포트를 사용하도록 조치했습니다.

## 리뷰에서 찾은 것과 고친 것
- 리뷰에서 찾은 문제 중 하나는 LLM의 응답을 JSON으로 파싱할 때 발생하는 오류였습니다. 이를 해결하기 위해 parse_llm_json 함수에서 JSON 파싱 실패 시 None을 반환하도록 수정하고, 이후 처리 로직에서 이를 적절히 처리하도록 개선했습니다. 또한, 위험도 판정 로직에서 문자열 비교 시 대소문자와 공백을 무시하도록 수정하여 정확한 판정을 할 수 있도록 했습니다.

## 캡스톤에서 더 해 보고 싶은 것
- 캡스톤 프로젝트에서는 LLM의 응답을 보다 정교하게 처리하고, 다양한 보안 경보 유형에 대한 대응 전략을 자동화하는 기능을 추가하고 싶습니다. 또한, 보고서 생성 시 **시각화** 요소를 포함하여 팀장에게 더 직관적인 정보를 제공할 수 있는 기능을 구현하고 싶습니다.
