  **A. 개발 서버 8082 외부 접속 — 접근통제**

  * 근거: 비교를 위해 서버 두 대를 켰습니다. `closed-web-8081`은 PORTS가 `127.0.0.1:8081->80/tcp`이고, 제 PC의 IP로 접속하면 거부됩니다. `open-web-8082`는 PORTS가 `0.0.0.0:8082->80/tcp`이고, 제 PC의 IP로 접속하면 `200`이 나옵니다. 따라서 8082는 모든 인터페이스에 열려 있어 사내 다른 PC에서도 접속됩니다.
  * 먼저 할 일: 외부 접속이 필요 없는 개발 서버이므로 `-p 127.0.0.1:8082:80`으로 다시 실행해 내부 전용으로 좁히겠습니다. 이후 제 PC의 IP로 접속했을 때 거부되는지 확인하겠습니다.

  **B. 개발 서버 8084 응답 없음 — 장애**

  * 근거: `docker ps`에서는 `Up`이지만, PORTS가 `0.0.0.0:8084->[ ]/tcp`로 컨테이너 쪽 포트가 nginx 대기 포트(80)와 다릅니다. 응답은 `000`이며 `docker logs`에 요청 줄이 없어, 요청이 nginx까지 도착하지 못한 것으로 판단됩니다. 정상 비교군 `compare-web-8085`(`->80/tcp`)는 `200`이 나오고 로그에도 요청 줄이 남습니다.
  * 먼저 할 일: `-p 8084:80`으로 다시 실행한 뒤, `200` 응답과 로그의 요청 줄을 확인하겠습니다.

  **C. 1초 안에 404 연속 — 위협 (탐색 시도)**

  * 근거: 12:13:50(KST) 같은 1초 안에 `/admin`, `/login`, `/.env`, `/wp-login.php`, `/backup.zip`을 연속으로 요청했고 모두 `404 153`으로 응답했습니다. User-Agent는 `curl/8.21.0`으로 일반 브라우저가 아닙니다. 경로가 관리자 페이지, 비밀키 파일, 백업 파일 같은 민감 경로뿐이라 단순 오류가 아니라 탐색 패턴입니다. `/index.html`만 `200`이었으므로 민감 파일 노출은 없었습니다. (재현이라 출처는 `172.17.0.1`(도커 게이트웨이)입니다.)
  * 먼저 할 일: 로그를 보존하겠습니다. 실제로 외부 IP에서 이런 요청이 오면 해당 IP를 차단하고, `.env`나 백업 파일이 웹 루트에 없는지 점검하겠습니다.

### 문제 3-1 · 거부 직후 허용 찾고 이유별 막대그래프 그리기

- (가) 내가 채운 코드를 붙여 넣어 주세요.
  - 쓸 내용: `# ←` 네 곳에 채운 코드(`json.loads` · 거부 후 허용 · `last` 기억 · 막대 출력 한 줄)
  - 답:미등록 기기 ## 2
    퇴사 계정 #### 4
    MFA 안 함 # 1
    해외 접속 # 1

```Python
line = json.loads(text)   # 1. 임시 값입니다. text 를 json.loads 로 딕셔너리로 바꾼 값으로 바꾼다   # ←
    user = line["user"]                                      # 이 줄의 계정
    now = to_min(line["time"])                               # 이 줄의 시각(분)
    # 2. user 가 last 에 있고, last[user][0] 이 "거부" 이고, line["decision"] 이 "허용" 이고, now - last[user][1] 이 10 이하이면 "[거부 후 허용]", user, line["time"], line["device"] 를 출력한다   # ←
    if user in last and last[user][0] == "거부" and line["decision"] == "허용" and now - last[user][1] <= 10:
        print("[거부 후 허용]", user, line["time"], line["device"])

    # 3. last[user] 에 (line["decision"], now) 를 기억한다   # ←
    last[user] = (line["decision"], now)
    if line["decision"] == "거부":                            # 거부 줄이면
        deny_reasons[line["reason"]] = deny_reasons.get(line["reason"], 0) + 1   # 그 이유의 건수를 1 늘린다(10/14(수)에 배운 방식)

for reason in deny_reasons:                                  # 이유를 하나씩 꺼낸다
    count = deny_reasons[reason]                             # 그 이유의 건수
    # 4. reason, "#" 를 count 만큼 반복한 글자, count 를 출력한다   # ←
    print(reason, "#" * count, count)
```
