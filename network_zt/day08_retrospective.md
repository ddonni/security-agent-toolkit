# 2과목 회고 (10/21(수))

## 잘 이해한 것

- 도커 `-p` 에 `127.0.0.1:` 을 붙이면 내 PC 안에서만, 빼면 `0.0.0.0`(모든 주소)으로 열린다는 것. `PORTS` 열과 `docker inspect` 의 `HostIp` 로 확인한다(`HostIp` 가 비어 있으면 모든 주소).
- `docker ps` 에 `Up` 이어도 서비스가 되는 것은 아니다. 응답 번호만 보지 말고 `PORTS` 의 컨테이너 쪽 포트와 `docker logs` 의 요청 줄, 정상 비교군을 같이 본다.
- 같은 `404` 도 출처 · 시각 · 경로 · 프로그램을 보면 정상(favicon)인지 탐색 시도인지 갈린다.
- 「거부 후 허용」은 후보일 뿐이고, 거부 이유와 기기가 바뀌었는지로 정상 재시도와 의심 건을 가른다.
- 새 자료가 오면 바뀐 것과 바뀌지 않은 것을 나눠 정정하고, 조치는 막는 위험과 정상 직원의 불편을 같이 적는다.

- 장애와 접근통제 구분(8일 차 2교시 알림 B). 「누가 접속하느냐에 따라 결과가 달라지는가」로 가른다.
