
# A사 Zero Trust 적용 방안

## 5대 원칙 적용 방안

- ID: 모든 접속 경로에 비밀번호와 MFA 인증이 필요하도록 바꾼다
- Device: 회사 등록 대장에 등록된 기기만 로그인할 수 있게 하고 기기 점검(백신, 패치 상태 등)을 항상 실시한다.
- Network: 서버 구역과 직원 PC 구역을 나누고, 필요한 포트만 연다
- Application: 각자 팀에 맞는(최소 권한 목록에 있는) 자원만 조회할 수 있게 한다
- Policy: 평소와 시간 위치 조회량이면 추가 인증을 실시한다

## 판단과 집행

- PDP(결정): 5대 원칙 기준으로 요청을 판단해 「허용 / 추가 인증 / 거부」를 결정한다
- PEP(집행): 사용자와 자원 사이에서 요청을 받아 PDP에 묻고, 받은 결정대로 집행한다

## 흐름도

```
사용자 --요청--> PEP --문의--> PDP
                  |  <--결정--   |
                  |              └ 판단 기준: ID(pw+MFA) · Device(등록·상태)
                  |                · Application(최소권한 목록) · Network(구역)
                  |                · Policy(시간·위치·조회량)
                  ├─ 허용      --> 자원 접근
                  ├─ 추가 인증 --> MFA 재요청 후 다시 판단
                  └─ 거부      --> 차단 + 기록
```

## 최소권한 기준 (목록에 없으면 거부)

- 영업팀: SALES(영업) 조회
