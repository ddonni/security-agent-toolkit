### 문제 4-2 · 허용 포트 목록 함수 채우고 흐름 그리기

- (가) 채운 `allowed_ports` 함수를 붙여 넣고, 실행해서 나온 출력 네 줄을 적어 주세요.
  - 쓸 내용: ① 채운 함수 ② 출력 네 줄
  - 답: [443]
    [445]
    [22, 80, 443, 445, 3389]
    []

```Python
def allowed_ports(src, dst, ports):
    result = []                              # ← 이 줄을 지우고 위 1 ~ 6 을 코드로 쓴다 (6줄
    for port in ports:
        action, no = judge(src, dst, port)      # judge 가 리턴한 두 값을 action 과 no 에 나눠 담는다
        if action == "permit":                      # action 이 "permit" 이면
            result.append(port)      
    return result
```

- (나) `judge` 함수의 흐름을 ASCII 도식(상자 · 화살표)으로 그려 아래 코드 블록에 넣어 주세요.
  - 쓸 내용: 코드 블록 안에 ASCII 도식을 직접 그리기(상자 안은 영어 · 숫자)
  - 답:

```

  ├── no ──► [ default_policy(src, dst) ]     │

       └── True ──► RETURN (rule[4], rule[0])
```

- (다) 🔍 `allowed_ports` 에서 `result = []` 를 `for` 위에 두는 이유는 무엇인가요? `for` 안에 두면 어떻게 되나요?
  - 쓸 내용: ① `result = []` 를 `for` 위에 두는 이유 ② `for` 안에 두면 달라지는 점
  - 답: for 안에다 두면 반복문이 반복될때마다 result 변수를 빈 리스트로 초기화 해버리기 때문에 for 밖에서 초기화를 해서 값이유지되도록 함.
